# 붉은 눈 — 실제 전투 그래픽 아틀라스

`assets/battle_atlas.webp`는 **GitHub main 브랜치에 업로드되어 있습니다**. 최신 `index.html`의 `RS_ART` 로더가 이 파일을 불러옵니다.

- 배경: 설원 수도원과 아르덴의 전투 지역
- 아군: 9명 × 대기/공격 2포즈
- 적: 일반·사냥꾼·거구 감염자 2포즈
- 보스: 기괴한 돌연변이 감염체 3포즈
- 기타: 화염·폭발 리소스 후보(기존 파티클 효과 유지)

**현재 공개용 아틀라스는 전송 용량을 줄인 140×164 픽셀 WebP 파일**입니다. 원본 아틀라스는 400×470 픽셀입니다. 게임은 좌표를 자동 변환하고 픽셀 경계를 살려 확대하지만, 고해상도 원본에 비해 디테일이 줄어듭니다. 원본으로 바꾸려면 같은 경로의 파일만 교체하면 됩니다. 게임 `index.html`을 예전 패키지 버전으로 덮어쓰지 마세요.

이미지가 로딩되지 않는 환경에서는 원래 캔버스 스프라이트로 돌아가도록 설계되어 있습니다.
