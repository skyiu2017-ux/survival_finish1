# 붉은 눈 — 전투 그래픽 리소스

이 폴더에는 새 전투 그래픽의 아틀라스 `battle_atlas.webp`(400×470)를 배치합니다.

현재 `index.html`의 전투 그래픽 로더는 `assets/battle_atlas.webp`를 불러옵니다. 이 이미지가 없으면 기존 픽셀 아트로 자동 대체합니다.

교사용 설치: 채팅에서 제공한 **붉은눈_메탈슬러그풍_전투그래픽_1차통합패키지.zip**을 풀고 `assets/battle_atlas.webp` **한 파일만** 이 폴더에 업로드하면 됩니다. `index.html`은 덮어쓰지 마세요. 기존 저장·수류탄·랭킹 기능이 유지되어야 합니다.

1차 통합판은 아군 9종 × 2포즈, 감염자 3종 × 2포즈, 거대 보스 3포즈, 설원 배경 및 이펙트 후보를 포함합니다. 이펙트는 차후 교체 예정이며 현재 전투 엔진의 효과를 유지합니다.
