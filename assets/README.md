# 붉은 눈 — 전투용 고해상도 그래픽

GitHub `main`의 최신 전투 그래픽은 다음 파일을 사용합니다.

- `battlefield-1600.webp`: 폭 1600픽셀의 설원 수도원 배경. 960×540 내부 전투 캔버스에 표시합니다.
- `companions-hd.webp`: 동료 9명 장면 (각 원본 176×224 픽셀) 및 배치용 카드 그래픽.
- `battle_atlas.webp`: **400×470픽셀 원본** 적·보스·효과·보조 그래픽. 이전 140×164 경량판을 원본으로 복구했습니다.
- `battle_bg_hd.webp`: 960×540 보조 배경 파일. 메인 전투는 더 큰 `battlefield-1600.webp`를 우선 사용합니다.

전투 그래픽 로딩에 실패하면 기존 게임의 코드 기반 도트 그래픽으로 복구합니다. 전투 캔버스의 물리 크기는 960×540이고, 터치와 동료 배치 계산에는 기존 320×180 논리 좌표를 유지합니다.

**주의:** 최신 `index.html`은 저장·학급 랭킹·문항 출제까지 통합되어 있습니다. 이전 배포 ZIP의 HTML로 덮어쓰지 마세요.
