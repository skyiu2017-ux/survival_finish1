# 붉은 눈(雪) — 1945, 아르덴 생존 기록

중학교 세계사 복습용 로그라이크 생존 게임입니다.

## 학생용 게임 링크

**https://skyiu2017-ux.github.io/survival_finish1/**

> 위 링크는 저장소 소유자가 GitHub Pages를 최초 활성화하면 작동합니다.

## 처음 한 번만 설정하기 (교사용)

1. [저장소](https://github.com/skyiu2017-ux/survival_finish1)의 **Settings** 탭을 엽니다.
2. 왼쪽 **Pages** 메뉴를 클릭합니다.
3. **Build and deployment → Source**를 **Deploy from a branch**로 선택합니다.
4. **Branch**에서 **main**, 폴더는 **/(root)**로 선택한 뒤 **Save**를 누릅니다.
5. GitHub에서 배포가 완료되면 위 학생용 게임 링크를 열어 확인합니다.

게임 내용은 루트 폴더의 `index.html`입니다. 이후 `index.html`이 바뀌면 GitHub Pages에도 자동 반영됩니다. 별도 GitHub Actions 설정은 필요 없습니다.

## 저장 후 이어하기

- **오전·오후 행동 선택 화면**에서 `💾 저장 후 나가기`를 누릅니다.
- 첫 화면의 `💾 저장된 도전 이어하기`로 같은 기기·같은 브라우저에서 다시 플레이합니다.
- 역사 문제 답변 중·원정 중·야간 전투 중에는 저장할 수 없습니다.
- 저장 기록은 **불러오는 즉시 소비**되므로, 다음에 계속하려면 다시 저장해야 합니다.
- 사망, 종전, 직접 기록 종료는 되돌릴 수 없습니다. 저장이 끝나기 전에 탭을 닫으면 진행 상황을 잃을 수 있습니다.
- 이 저장은 브라우저 로컬 저장소를 사용하며 서버에 업로드되지 않습니다. 로컬 저장소를 조작하는 고의적 부정행위까지는 방지하지 못합니다.

## 2026년 11월 22일 — 학급 테스트 의견 반영

- **역사 문제**: 일반 정답 문항은 한 판에서 중복하지 않도록 유형별 기록을 유지합니다. 아침 점호에서는 같은 개념의 출제를 가능하면 최소 7일 띄웁니다. 틀린 문제는 7~11일 뒤 다시 확인합니다. 전체 문제은행이 소진되었을 때만 21일 이상 지난 문제를 복습하며, 정답에 따른 추가 지식은 지급하지 않습니다.
- **거인**: 역사 개념 입력 3회로 시작해 26/51/76일째부터 각각 4/5/6회로 증가합니다. 초성 문제를 소진하면 아직 출제되지 않은 객관식의 핵심 용어를 입력 문제로 바꿉니다.
- **전투**: 전반적인 사격 속도·폭발 범위와 화염병의 피해량/지속 시간을 낮췄습니다. **실내 유입이 0일 때** 방어선이 수십씩 줄어드는 문제를 수정했습니다. 특히 성공적 방어의 손실은 작게 제한합니다.
- **탐색**: 낮은 위험 지역은 소량, 높은 위험 지역은 다량의 식량·물자를 보상합니다. 같은 장소는 방문 후 **4일 동안 탐색할 수 없습니다**.
- **자원과 사기**: 누적 지식은 랭킹에 그대로 남고 소비 가능한 지식은 최대 20으로 제한됩니다. `지식 활용 · 작전회의`에서 치료·보강·정찰 등에 지식을 쓸 수 있습니다. 높은 사기 상태일수록 추가 상승이 느리고 시간이 지날수록 유지가 어려워집니다. 과잉 식량·물자에는 비축 손실이 발생합니다.
- **판단형 이벤트**: 포병·누더기 군복의 남자·부상자·문밖 울음소리·야간 목소리에 서로 다른 정체와 단서를 부여했습니다. 인종 등 외모 자체는 위험 판정의 근거로 사용하지 않습니다.
- **그래픽**: `assets/battle_atlas.webp`를 GitHub에 실제 업로드하고 최신 `index.html`의 기존 전투 엔진에 연결했습니다. 브라우저가 이미지를 읽지 못하면 종전 도트 그래픽으로 복귀합니다.

이 버전은 문항 중복 모의 출제와 전투 조건별 단위 시험을 거쳤습니다. 실제 학생 조작에 따른 전체 **100일 생존률은 아직 확정된 수치가 없습니다**. 배포 전에 모바일/PC에서 그래픽, 화염병 투척, 거인 입력, 이어하기를 확인하세요.

## 전투·탐색 변경

- 수류탄은 첫날 3개를 보유하며, 사용 후에는 탐색·수첩·원정에서 낮은 확률로 획득해야 합니다.
- 화염병은 별도 개수가 아니라 **물자 1개/회**를 소비합니다. 조피아 수리와 같은 자원을 사용합니다.
- 종탑·창가·전방은 사거리, 사격 간격, 광역 공격, 근접 저지에서 다른 장단점을 가지며 동료 신뢰도가 사격 효율을 일부 조정합니다.
- 밤마다 달이 구름에 가려지는 경우가 발생하고, 그날 밤에는 은신이 유리해집니다. 정확한 확률은 학생에게 숨깁니다.
- 같은 장소는 4일간 재방문할 수 없고, 반복 방문 시 남은 물자도 감소합니다. 바스토뉴 미군 보급창 원정은 한 번만 방문할 수 있습니다.

## 랭킹과 학생 개인정보

- 순위: **생존 일수 → 누적 획득 지식 → 종료 시 남은 식량 → 종료 시 남은 물자**, 모두 높은 순입니다.
- Google Apps Script 웹 앱 주소가 게임 파일에 설정되어 있습니다. **공용 랭킹이 제대로 동작하려면 이 Google Apps Script 서버가 별도로 정상 배포되어 있어야 합니다.** GitHub는 게임 웹페이지만 호스팅합니다.
- 학생에게는 실명·학번 대신 교사가 배정한 **익명 코드** 사용을 권장합니다.
- 브라우저에서 제출되는 기록은 기술적으로 조작할 수 있으므로, 공식 성적 산출에 사용하려면 추가 인증·검증이 필요합니다.
